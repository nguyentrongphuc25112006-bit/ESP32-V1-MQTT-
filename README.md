# ESP32-V1-MQTT-
This project uses an ESP32 DevKit V1 to control an LED via MQTT. The ESP32 connects to the MQTT broker provided by Nexora and communicates with MQTTX. Users can remotely turn the LED ON or OFF by sending commands through a specific MQTT topic.
## Nexora MQTT Broker

This project uses the MQTT broker provided by https://mqtt.nexora.id.vn/.
